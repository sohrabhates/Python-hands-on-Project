## 🔐 Password Manager

A desktop password manager built with **Python and Tkinter**.

### Features

- 🔒 Fernet-based password encryption
- ➕ Add and save passwords
- 👁️ Show/hide saved passwords
- ⚡ Secure random password generator
- 📋 Copy generated passwords
- 💾 Local encrypted password storage
- 🎨 Dark-themed graphical interface
- 🧩 Separate frontend and backend modules

### Technologies

- Python
- Tkinter
- Cryptography
- Fernet

> **Security Note:** This project is currently a learning project and is not intended to be used as a production-grade password manager. Encryption keys and local password storage files are excluded from version control.
